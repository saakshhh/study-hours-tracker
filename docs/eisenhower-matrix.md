DO – Your MVP (Urgent + Important)
Allow users to record a study session by entering the course name, date, and number of minutes studied.
Save study sessions to a local CSV file and load previous records when the program starts.
Display a weekly summary showing total study hours and the time spent on each course.

SCHEDULE – For V2.0+ (Important + Not Urgent)
Allow users to set weekly study goals and track their progress.
Add the ability to edit or delete previously recorded study sessions.
Display study trends over the past few weeks to compare study habits.
Include simple text-based bar charts to visualize study hours by course.

DELEGATE – Use Existing Libraries (Urgent + Not Important)
Use Java's Scanner class to handle user input instead of creating a custom input system.
Use Java's LocalDate class to manage dates and identify study sessions from the current week.
Use Java's built-in file handling tools (java.nio.file) to save and read CSV files.
Use Java's HashMap to organize study hours by course and calculate totals.
